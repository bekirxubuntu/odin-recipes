# Odin Recipes

This is the first project from **The Odin Project** Foundations path. It is a basic recipe website built to practice fundamental web development skills.

## Live Demo
You can view the main page by opening `index.html` in any web browser.

## Features & Skills Practiced
- **HTML Boilerplate & Structure:** Proper document setup with standard HTML tags.
- **Navigation:** Relative paths connecting the main `index.html` with individual recipe pages.
- **Formatting & Semantic Elements:**
  - `<h1>` and `<h2>` headings for section hierarchy.
  - Unordered lists (`<ul>`) for ingredients.
  - Ordered lists (`<ol>`) for step-by-step instructions.
  - Image integration (`<img>`) with optimized dimensions.
- **Git & Version Control:** Practicing atomic commits and detailed commit messages adhering to TOP guidelines.
